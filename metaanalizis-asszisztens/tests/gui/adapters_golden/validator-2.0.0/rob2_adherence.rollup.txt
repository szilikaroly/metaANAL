  Domain 1 (Randomisation process): LOW  — 2019 algorithm: 1.2 'Yes' → 1.3 'No' → 1.1 'Yes'
  Domain 2 (Deviations from intended interventions): SOME CONCERNS / UNCLEAR  — 2019 algorithm: 2.1 'Yes' → 2.2 'No' → 2.3 'Yes' → 2.4 'Yes' → 2.5 'No' → 2.6 'Yes'
  Domain 3 (Missing outcome data): LOW  — 2019 algorithm: 3.1 'Yes'
  Domain 4 (Measurement of the outcome): LOW  — 2019 algorithm: 4.1 'No' → 4.2 'No' → 4.3 'No'
  Domain 5 (Selection of the reported result): LOW  — 2019 algorithm: 5.2 'No' → 5.3 'No' → 5.1 'Yes'

  Implied overall: SOME CONCERNS — at least one domain has some concerns and none is high. RoB 2 also allows High when several domains with some concerns together substantially lower confidence in the result: that is a judgement — state it and why if you make it.
  Domain verdicts follow the RoB 2 algorithms of the 22 August 2019 guidance (effect of adhering variant of domain 2). For a published assessment, cross-check with the official Excel tool; an override is legitimate when it is stated with its reason.
